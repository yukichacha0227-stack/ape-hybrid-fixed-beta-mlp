# 中間発表資料対応版の再現手順

## 保存予測から指標を再計算

リポジトリルートで次を実行する。Python 3.11以降の標準ライブラリだけを使う。

```bash
python studies/interim_v1_20261113/verify_release.py
```

4個のTest予測CSVから96行のR²・MAE・RMSE・MAPE・MBEを独立再計算し、レーダー40値、同一時刻条件、出典ハッシュ、図・READMEのリンクを確認する。全指標の許容誤差は1e-9。MBEは予測−正解。

入力CSVはこの公開版に含まれる派生した1時間平均APE正解・予測であり、元の分光観測や10特徴量の観測入力ではない。原本DS・NEDO配布ファイルは含めていない。

## 保存モデルを利用する場合

`model_inventory.json`に22条件の出典を記載。`models/{design}/{site}/{source_model}/`に学習済みPyTorch重み、config、architecture、model_report、学習履歴を保存した。MLP、TCN、SelfAttentionと、native／common_hoursのNEDO参照LSTMが含まれる。

`model.pt`は`state_dict`に加えて学習記録とconfig fingerprintを含む当時のチェックポイント。PyTorchとNumPy等の互換性を確認し、信頼できるファイルだけを読み込む。推論クラスは `source_snapshot/naganuma_10feature_models.py` と `source_snapshot/naganuma_10feature_extended_models.py`。MLP/TCN/SelfAttentionは前者、LSTMは後者の`create_model`から作る。

`config.json`のfeature_names順に静的・履歴特徴量を作り、`feature_scaler.json`のmean/scaleで標準化する。入力は現在を含む7時間位置とavailability列を持つシーケンスで、MLPは最後の位置を利用する。`residual_mean`・`residual_std`でネットワーク出力をeVの残差へ戻し、β予測に加える。校正後を求める場合は `model_report.json` の面別slope/intercept/clip_absを適用する。

標準化は `(x - mean) / scale`。JSONは旧joblibのStandardScalerから数値を取り出して作り、元オブジェクトのtransformとの一致を検算した。βの標準化空間の係数は `protocol/`、元単位の表面別係数は `beta_effective_coefficients.csv`。

推論に必要な現地の物理入力と初期履歴を別途用意する必要がある。重みだけで任意地点のAPEが得られるわけではない。この公開では、全Test入力シーケンスを配布した重み再実行は提供していない。保存Test予測からの指標検算は入力観測なしで可能。

## 同じ手法で再学習する場合

`source_snapshot/`は実行に使用した旧コードを元の相対構造のまま保存したもの。データ探索や出力先には当時の研究ワークスペース構造が残っており、クローン直後に原本なしで実行できる学習CLIではない。

主な実装は次のとおり。

| ファイル | 役割 |
|---|---|
| `tsukuba_naganuma_10feature_data.py` | 2地点データの時刻整合、native/common_hours、β・OOFと分割の準備 |
| `tsukuba_naganuma_10feature_experiment.py` | 共通設定のMLP/TCN/SelfAttention学習ジョブ |
| `naganuma_10feature_experiment.py` | 35列特徴量、残差教師、再帰推論、面別校正 |
| `naganuma_10feature_models.py` | 補正モデル・学習ループ |
| `naganuma_f_to3_hourly.py` と配下のF参照コード | 1時間平均化、Ridge、時間順OOF、基礎評価 |
| `plot_nedo_mlp_calibrated_scatter.py` | 保存Testからの散布図 |
| `plot_nedo_five_model_radar.py`、`plot_nedo_mape_explicit_values.py` | 保存予測からの5モデル比較図 |

元ワークスペースでは、2地点DS、検証用つくばの元APE pickle、NEDO気象観測、MERRA-2由来大気列、既存の長沼学習成果等を使用する。`source_snapshot/`のコードを対応ワークスペースへ配置し、必要なデータを各提供元の条件に従って取得・配置する。元コードには、既存の長沼モデルを再利用する処理も含まれる。重みと保存予測の再利用は追加学習・転移学習ではない。

Trainの標準化・時間順5fold OOF・gap6、Earlyのみでのearly stopping、CALのみでの校正、Testでの自己予測残差履歴、seed42、同じ時間分割を維持する。新規研究ではβを両面共通にする最新方針を適用し、この資料対応版の再現とは区別する。

## 既存のつくば5変数版

リポジトリの既存パッケージ・学習CLIはそのまま残っている。[旧README](../../docs/historical/README_tsukuba_five_feature_main.md)を参照すること。インストールと既存テストはルートで実行する。

```bash
python -m pip install -e ".[dev]"
pytest
```

そのつくば5変数版のTest各面1,822時間、R²=0.6567/0.7795は、この資料の10特徴量2地点版とは異なる解析条件である。
